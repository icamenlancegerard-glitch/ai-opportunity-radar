# AI Opportunity Radar

**MVP 0.1 — evidence-first AI opportunity discovery**

AI Opportunity Radar is a lightweight web prototype for finding AI-related work opportunities while keeping uncertainty visible.

## Current MVP
- Search by title, company, skill, or location
- Filter by opportunity type
- Filter by work mode
- Evidence-status badges
- Direct source links
- Responsive mobile-friendly UI
- Explicit warning against treating unverified listings as confirmed

## Evidence rule
The bundled records are **demo seed records**, not a live job feed. “Source recorded” means only that a source URL is recorded. It does **not** establish that an opportunity is current, that the employer is verified, that the pay is accurate, or that the user is eligible. Re-check the source before applying.
